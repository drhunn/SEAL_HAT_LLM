# Feature specs

This directory holds feature-family and feature-slice working documents.

Use it with:
- `../feature-map.md`
- `../branch-workflow.md`

## Structure

- `_template/` — starting point for a new feature spec set
- one folder per feature family

Each feature-family folder should contain at least:
- `README.md`
- `acceptance-criteria.md`
- `test-plan.md`

When cutting a feature branch, copy the structure that fits the slice and make the included subfeatures explicit.
