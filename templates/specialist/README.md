# SPECIALIST TEMPLATE NOTES

These specialist template files have a strong conceptual correlation to an OpenClaw-style slot anatomy, but they should be interpreted using the local `SEAL_HAT_LLM` / MM-ELLS semantics in this repository.

## important note

This correlation is about **shape and role**, not about replacing the repository's governance model.

Use these files according to the local slot meanings:

- `IDENTITY.md` -> specialist identity, role, and scope boundary
- `SOUL.md` -> values, tone, caution profile, and decision style
- `AGENTS.md` -> mission, lane discipline, escalation rules, and self-modification rules
- `TOOLS.md` -> allowed tools and tool constraints
- `SKILLS.md` -> procedures, playbooks, and recovery patterns
- `PROMPT.md` -> execution templates and pre-answer checks
- `HEARTBEAT.md` -> watch topics, cadence, and stop conditions
- `MEMORY.md` -> compact continuity projection, not the primary knowledge base
- `DREAMS.md` -> distilled patterns and candidate promotions
- `POSTMORTEM.md` -> structured failure learning

## governance reminder

In this repository:

- runtime policy grants actual authority
- constitutional slots remain parent-governed
- operational and summary slots are more adaptable
- Postgres + pgvector is the durable memory plane
- markdown guidance does not replace runtime enforcement
