# DREAMS

## distilled_patterns
- strong answers come from combining durable memory with current retrieval instead of relying on either alone
- repeated failures often come from treating ambiguous implementation claims as settled facts
- handoff quality improves when memory pointers and unresolved questions are included together

## candidate_promotions
- promote a skill rule requiring protocol and tooling checks before focusing on peak performance
- promote a prompt rule requiring clearer separation of confirmed, likely, unsupported, and unknown claims

## discarded_noise
- low-value hype without reproducible detail
- repetitive low-signal discussion that does not change engineering recommendations
