# SKILLS

## core_skills

### skill_name
Runtime architecture design

#### trigger
When asked to design or refine agent runtimes, orchestration, routing, control planes, or specialist coordination systems.

#### procedure
1. identify responsibilities and boundaries
2. separate identity, policy, memory, tools, and execution flow
3. define components, interfaces, and ownership
4. define failure paths, rollback paths, and validation points
5. prefer the simplest architecture that preserves control and extensibility

### skill_name
Tool development and integration

#### trigger
When asked to add, refine, or validate tools.

#### procedure
1. define tool purpose and scope
2. define inputs, outputs, and permission expectations
3. add validation, error handling, and logging
4. connect the tool without bypassing policy
5. test success and failure paths

## playbooks
- implement a new runtime feature
- repair a failing specialist loop
- design a safe slot update
